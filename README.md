# Visual Morse Decoder

A retro-styled single-page web app for learning and practicing Morse code visually.

## Overview

Visual Morse Decoder lets users input dots and dashes through buttons or keyboard shortcuts, highlights the active path on the Morse tree in real time, and auto-commits a decoded character after a short idle period.

## Features

- Dot / dash input via buttons and keyboard shortcuts
- Real-time SVG tree highlighting for the current Morse path
- Auto-commit timer with progress feedback
- Clear all output and input state
- Responsive layout for desktop, tablet, and mobile

## Development Process

- The product specification in [spec.md](spec.md) was generated by Gemini 3.5 Flash.
- The implementation in [index.html](index.html) was generated by GitHub Copilot.
- A human made only minor code adjustments and UI refinements.

## Run Locally

The app is intended to be run through a local static file server. Opening [index.html](index.html) directly in a browser may fail because the app is loaded as ES modules.

### Recommended way

1. Start a local server with Python:

```bash
python3 -m http.server 8000
```

2. Open the app in your browser:

```text
http://localhost:8000/
```

### Alternative

If you prefer to use a different local server, the same `http://localhost:8000/` flow applies.
